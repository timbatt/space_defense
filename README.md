# Tower Defense Game - C++ with SFML

## Features:
- Good guys
- Bad guys.
- Weaponry.
- Cool partical effects.
- Awesome sound effects.



### Install Dependancies (Debian)
`apt install build-essential libsfml-dev`

### Clone and Compile
```
git clone https://github.com/timbatt/tower_defense
cd tower_defense
make
```

### Run
`./main`
